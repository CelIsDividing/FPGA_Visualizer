1. FILE: main.py

DESCRIPTION:
Main FPGA visualization tool application. Flask web application that 
coordinates all system components.

CLASSES:
------------------------------------------------------------------------
Class: FPGAVisualizationApp
Description: Main class of the FPGA visualization tool

METHODS/FUNCTIONS:
------------------------------------------------------------------------

__init__(self)
    Initializes Flask application, parsers, visualizers and configures CORS.
    Sets current data (architecture, circuit, routing) to None.

_setup_routes(self)
    Sets up all Flask routes for the web application.
    Defines endpoints for uploading files, visualization, analysis and download.

@app.route('/')
def index()
    Renders the main HTML page of the application.

@app.route('/upload/architecture', methods=['POST'])
def upload_architecture()
    Route for uploading the FPGA architecture (.xml file).
    Parses the XML file and loads the architecture using ArchitectureParser.
    Returns a JSON response with the parsed architecture or an error.

@app.route('/upload/routing', methods=['POST'])
def upload_routing()
    Route for uploading routing results (.route file).
    Requires the architecture to be loaded previously.
    Parses the .route file and returns the routing data.

@app.route('/api/parse_routing', methods=['POST'])
def parse_routing()
    Parses the .route file and returns a list of signals.
    Extracts dimensions from the file, creates the architecture if it does not exist,
    and returns information about the signals (net_name, segment_count, fanout).

@app.route('/upload/circuit', methods=['POST'])
def upload_circuit()
    Route for uploading a circuit (.v or .blif file).
    Parses the Verilog or BLIF file and returns data about the circuit.

@app.route('/api/visualize', methods=['POST'])
def visualize_selected_signals()
    Visualizes only the selected signals.
    Receives a JSON with a list of signals and display options (grid, directions, heatmap).
    Filters the routes and generates a PNG image of the visualization.

@app.route('/visualize/signals', methods=['POST'])
def visualize_signals()
    Endpoint for visualizing routing (the image is saved in the OUTPUT folder).
    Generates a timestamped image of the routing visualization.

@app.route('/analysis/conflicts', methods=['POST'])
def analyze_conflicts()
    Route for conflict analysis - works with routing or circuit data.
    Builds the conflict graph, identifies hubs, computes metrics.
    Generates and saves a visualization of the conflict graph.

@app.route('/analysis/statistics', methods=['GET'])
def get_statistics()
    Route for statistical analysis.
    Computes complex statistics for the circuit and architecture.

@app.route('/demo', methods=['GET'])
def create_demo()
    Route for creating demo data.
    Generates test architecture (3x10) and test circuit with 14 signals.

@app.route('/download/<path:filename>')
def download_file(filename)
    Route for downloading generated files from the OUTPUT folder.
    Validates the filename for security.

@app.route('/static/output/<path:filename>')
def static_output_file(filename)
    Route for static files from the output folder.

@app.route('/visualize/congestion', methods=['POST'])
def visualize_congestion()
    Route for visualizing congestion.
    Generates a congestion heat map and a report.

@app.route('/web/data', methods=['GET'])
def get_web_data()
    Route for web visualization data.
    Creates JSON data for interactive visualization.

run(self, host=None, port=None, debug=None)
    Runs the Flask application.
    Creates necessary directories, checks permissions,
    and prints all registered routes.

main()
    Main function to run the application.
    Instantiates FPGAVisualizationApp and starts the server.

DESCRIPTION:
Model classes for representing routing results and trees.

CLASSES:
------------------------------------------------------------------------
Class: RouteSegment
Description: Node in routing tree (not just a segment!)

Attributes:
    node_id: Node ID
    node_type: Node type (SOURCE, OPIN, CHANX, CHANY, IPIN, SINK)
    x, y: Node coordinates
    track: Track number in channel
    switch_id: Switch ID
    pad: Pad number (for IO blocks)
    children: List of children in tree
    parent: Parent in tree

METHODS/FUNCTIONS:
------------------------------------------------------------------------

is_io_pad(self) -> bool
    Whether it is an IO pad (SOURCE/SINK with a Pad label).
    Checks whether pad >= 0.

add_child(self, child)
    Adds child node to tree.
    Sets parent link on child.

is_leaf(self) -> bool
    Whether it is a leaf (SINK node).
    Checks if it has no children and is of type SINK.

is_root(self) -> bool
    Whether it is root (SOURCE node).
    Checks if it has no parent and is of type SOURCE.

get_path_to_root(self) -> List[RouteSegment]
    Returns path from this node to root.
    Starts from current node and follows parent links.

get_all_paths_to_leaves(self) -> List[List[RouteSegment]]
    Recursively returns all paths from this node to leaves.
    DFS traversal through tree.

to_dict(self, include_children=False) -> Dict
    Serialization to dict.
    Optionally includes child nodes.

------------------------------------------------------------------------
Class: NetRoute
Description: Routing tree for a single net

Attributes:
    net_name: Net name
    segments: Flat list of segments (legacy)
    root: Tree root (SOURCE node)

METHODS/FUNCTIONS:
------------------------------------------------------------------------

build_tree_from_segments(self)
    Converts linear list of segments to tree using VPR routing semantics.
    Finds SOURCE node and builds tree using _build_vpr_tree_sequential.

_build_vpr_tree_sequential(self)
    Builds tree from VPR route file sequential format.
    Parses segments sequentially, detects branch points.

_find_node_in_tree(self, root, node_id) -> Optional[RouteSegment]
    Recursively finds a node with given ID in the tree.
    DFS search through tree.

_find_appropriate_parent_for_next_segment(self, next_index) -> RouteSegment
    Find the appropriate parent for the next segment in sequence.
    Used when building the tree.

_find_routing_connection_point(self, target_seg) -> Optional[RouteSegment]
    Find a node in the tree that could logically connect to target segment.
    Helper function for connecting segments.

_build_tree_recursive(self, current_node, node_map, visited)
    Recursively builds the tree based on routing logic.

_find_next_nodes(self, current, node_map, visited) -> List[RouteSegment]
    Finds the next nodes in the routing sequence.
    Implements VPR routing rules.

_is_adjacent_or_same(self, node1, node2) -> bool
    Checks whether the nodes are adjacent or at the same location.
    Manhattan distance <= 1.

_is_routing_continuation(self, current, next_node) -> bool
    Checks whether next_node is a logical continuation of the routing path.
    Checks CHANX/CHANY rules.

get_all_source_to_sink_paths(self) -> List[List[RouteSegment]]
    Returns all paths from SOURCE to all SINKs.
    Calls root.get_all_paths_to_leaves().

get_path_coordinates(self) -> List[List[tuple]]
    Returns coordinates of all paths (for visualization).
    Extracts (x,y) coordinates from all paths.

to_dict(self, include_tree=True) -> Dict
    Serialization with the tree structure.
    Optionally includes the tree and paths.

------------------------------------------------------------------------
Class: RoutingResult
Description: Aggregator of routing results for all nets

Attributes:
    routes: List of NetRoute objects
    congestion: Congestion map
    metadata: Additional metadata
    circuit: Reference to Circuit
    architecture: Reference to FPGAArchitecture
    successful: Whether routing was successful
    total_wire_length: Total wire length
    iteration_count: Number of iterations
    timing_data: Timing data

METHODS/FUNCTIONS:
------------------------------------------------------------------------

calculate_congestion_metrics(self) -> Dict[str, float]
    Calculates various congestion metrics.
    Returns max, avg, min, and number of congested segments.

get_high_congestion_segments(self, threshold=0.8) -> List[str]
    Returns segments with high congestion.
    Filters segments above the threshold.

to_dict(self) -> Dict
    Serialization to a dictionary.

get_route_statistics(self) -> Dict[str, Any]
    Statistics of the routing tree.
    Computes the number of nets with branchings, max fanout, avg path length.

    - If there are large clusters -> regrouping
    - If the congestion entropy is large -> redistribution
